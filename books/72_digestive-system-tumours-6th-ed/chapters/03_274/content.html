Differences between the printed books and the website

The content of the printed books and that of the website are derived from the same database, so they have the same headings and the text is identical (except for a few corrections; see Corrigenda, below). The major differences are that the website has many more figures, including whole slide images; clickable citations; and a full reference list for the volume.

Classifications evolve, and so will the website, with more hyperlinks planned to make navigation between the text and relevant figures easier. We also hope to add more whole slide images: at least one for each tumour type/subtype.
